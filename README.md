# Auth App

Login and register app with a dashboard.

**Stack:** React (frontend), Node.js + Express (backend), PostgreSQL (database).

## Setup
1. Create the database `authdb`, then run `backend/schema.sql`.
2. `cd backend`, copy `.env.example` to `.env`, and fill in your values.
3. `npm install`, then `npm run dev` (API on port 5000).
4. Frontend instructions will be added once it is built.
